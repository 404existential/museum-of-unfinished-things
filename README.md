# The Museum of Unfinished Things

A digital archive of projects, ideas, experiments, ambitions and other things that were started but never completed.

## Included

- Editorial museum-style homepage
- 30 sample artifacts
- Search and category filtering
- Artifact detail records
- Curated exhibitions
- Artifact deposit/submission flow
- Local browser persistence for submitted artifacts
- Responsive mobile layout
- GitHub Pages-ready static site

## Run locally

Open `index.html` directly, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## GitHub Pages

In GitHub open **Settings → Pages**, select the `main` branch and `/ (root)`, then save.

## Future upgrades

A production version can add Firebase/Firestore, authentication, image uploads, moderation, curator tools, permanent artifact timelines and real full-text search.
